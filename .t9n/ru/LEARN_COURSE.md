# Программа: HTML, CSS и браузерный JavaScript

Курсы для тех, кто хочет понимать, **почему** браузер делает то, что делает, а не заучивать теги.
Каждый урок сразу вводит настоящие понятия (дерево документа, селектор, каскад, поток) и опирается
на предыдущие. Порядок ниже — рекомендуемый; ссылки «назад / вперёд» на страницах курсов идут в этом же порядке.

Все курсы читаются прямо здесь, на Codeberg. Примеры спрятаны в раскрывающиеся блоки; ссылка
**see preview & continue study** открывает тот же курс на странице, где каждый пример показан вживую.

Имена файлов: `LEARN_{ТЕХНОЛОГИЯ}_{ТЕМА}_COURSE.md` — легко фильтровать (`LEARN_CSS_*`) и читать в URL.
