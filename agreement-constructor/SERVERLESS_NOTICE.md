# Serverless artifact

`html@5_serverless/` is the constructor as a static site for any static host. It is the same editor as the single
file: everything is computed in the page, templates and documents live in the visitor's browser (IndexedDB of that
site), files leave as downloads (template / document JSON, the HTML copy of a contract, compiled templates). There is
no backend build: nothing here needs a server, and nothing is sent to one.
