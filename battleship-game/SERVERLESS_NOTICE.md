# Serverless build

`html@5_serverless/` is the game as a static site for any static host (GitHub Pages, Codeberg Pages, itch.io). It
plays offline against bots and, as a client, joins online rooms on a Sea Battle server whose address the player enters
(the backend build, or any `rooms/` service with the `battleship` game; CORS is open). Invite links carry the server.
