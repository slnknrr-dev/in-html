# Single-file offline build

`html@5_offline_singlefile/index.html` is the whole game in one self-contained HTML file with no network code at all:
play against the bots on every ruleset, place fleets, watch replays with the information of every shot, study your
style, build your own seas, shapes and fleets in the constructor. Open it from disk (`file://`), upload it to itch.io
as an HTML game, or host it anywhere. Online rooms are hidden in this build (its rooms client has no network code).
Settings, own rulesets, bots, saved layouts, the profile and saved games stay in the browser's local storage.
