# Serverless artifact

`html@5_serverless/` is the generator as a static site for any static host. Its addition over the single file is the
link: "Copy link" puts the share code into the address (`#code=…`), so a rug opens for anyone from a URL. Hosted on
the same site as Embroidery Studio's serverless build, "Send to Embroidery Studio" hands the cross-stitch scheme over
in the browser, and the studio offers it as soon as it is opened; elsewhere the downloaded scheme file is opened in
the studio. There is no backend build: nothing in the generator needs a server.
