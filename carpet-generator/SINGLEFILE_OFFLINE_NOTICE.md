# Single-file offline artifact

`html@5_offline_singlefile/index.html` is the whole generator in one self-contained HTML file with no network code:
traditions, seeds and share codes, size and knot density, dye palettes, design options, the pile / design / knotting
chart views, yarn estimates, the motif editor and every export (PNG, SVG, knotting PDF, cross-stitch PDF, OXS, scheme
JSON). Open it from disk (`file://`), keep it on a phone or a USB stick. A share code pasted into the code field
rebuilds the same rug; your own motifs stay in this browser. "Send to Embroidery Studio" downloads the scheme file,
which the studio (any build) opens.
