# Single-file offline build

`html@5_offline_singlefile/index.html` is the whole game in one self-contained HTML file with no network code at all:
play against the strategist bots, watch replays, study your style, build your own variants in the constructor. Open
it from disk (`file://`), upload it to itch.io as an HTML game, or host it anywhere. Online rooms are hidden in this
build. Settings, own rulesets, bots, the profile and saved games stay in the browser's local storage.
