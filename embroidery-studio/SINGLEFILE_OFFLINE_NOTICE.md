# Single-file offline artifact

`html@5_offline_singlefile/index.html` is the whole studio in one self-contained HTML file with no network code at
all (`remote.offline.js`): the built-in catalogue of schemes, the chart viewer that remembers your stitches, the
editor, the picture converter, PDF / OXS / JSON / PNG / SVG exports and printing. Open it from disk (`file://`), keep
it on a phone or a USB stick, e-mail it. Your charts and stitching progress stay in this browser (IndexedDB); a ZIP
backup is in "My schemes". There is no community catalogue, no uploads and no progress sync in this build.
