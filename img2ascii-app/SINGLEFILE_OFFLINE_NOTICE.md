# Single-file offline build

`html@5_offline_singlefile/` holds the ASCII art converter as self-contained HTML (`index.html`): scripts, styles and
icons are inlined and nothing is fetched — the build fails on any network API or remote resource. Open a file from
disk (`file://`), put it on a USB stick, send it by e-mail or host it anywhere. Pictures and the camera are processed
in the page; results leave as downloads or copies.
