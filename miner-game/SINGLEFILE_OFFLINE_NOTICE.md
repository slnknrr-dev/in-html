# Single-file offline build

`html@5_offline_singlefile/index.html` is the whole game in one self-contained HTML file: scripts, styles and icons
are inlined, nothing is fetched. Open it from disk (`file://`), put it on a USB stick, upload it to itch.io as an
HTML game, or host it anywhere. Settings, statistics, best times and replays stay in the browser's local storage.
