# Serverless artifact

`html@5_serverless/` is the README editor as a static site for any static host. It is the same editor as the single
file; the difference is the default for remote images: hosted on the web, the README's own remote pictures (badges
with live values, screenshots) are shown at once — the switch in More ▸ Load remote images turns that off. There is
no backend build: the editor keeps the text in the browser and saves files through the browser.
