# Serverless build

`html@5_serverless/` is the studio as a static site for any static host (GitHub Pages, Codeberg Pages, a shop's own
domain). Everything runs in the visitor's browser - drafting, the cloth simulation, rendering and every export - and
nothing is sent to a server: projects stay in the browser's storage and travel as files. The same modules are what a
landing or shop page imports to show garment previews (see `mockup/README.md`).
