# Single-file offline build

`html@5_offline_singlefile/index.html` is the whole studio in one self-contained HTML file with no network code at
all: model a body, draft garments and whole outfits, layer the details, weave or knit the fabric, design prints, drape
everything in 3D and export patterns, layouts and mockups. Open it from disk (`file://`), keep it on a USB stick or
host it anywhere. Projects stay in the browser's storage (IndexedDB) and travel as project files; uploaded artwork is
kept inside the project.
