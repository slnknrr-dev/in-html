# xml

**XML.** A small strict XML 1.0 parser and serializer with tree helpers for data formats (OOXML, ODF, KDBX, SVG). No DTDs and no external entities.

| module | contents |
| --- | --- |
| `xml.js` | a small, strict XML 1.0 parser and serializer for data formats (KDBX, OOXML, SVG, feeds). No DTDs, no external entities (never fetched or expanded); the five predefined entities and character references only. |

The header comment of each module documents its API.
